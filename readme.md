# 🕰️ Responsive Analog Clock

A responsive and animated analog clock built with **HTML**, **CSS**, and **JavaScript**. The clock updates in real time and features a dark theme with modern design aesthetics.

---

## 🔧 Features

- Real-time dynamic analog clock
- Responsive design for all screen sizes
- Smooth rotation of hour, minute, and second hands
- CSS-powered circular layout
- Glassmorphic UI with soft glow and shadows
